# 백범일지 · 白凡逸志

김구 선생의 자서전 《백범일지》를 Typst로 다시 세운 책이다. 1997년 돌베개 도진순 주해본의 2016년 전자책을 저본으로 삼아, 본문·주해·사진·연보를 그대로 옮기고 조판만 새로 했다.

金九 先生의 自敍傳 《白凡逸志》를 Typst로 다시 세운 冊이다. 一九九七年 돌베개 都珍淳 註解本의 二〇一六年 電子冊을 底本으로 삼아, 本文·註解·寫眞·年譜를 그대로 옮기고 組版만 새로 했다.

金九先生自敍傳《白凡逸志》，今以 Typst 重刊。底本者，一九九七年돌베개社都珍淳註解本之二〇一六年電子版也。本文、註解、寫眞、年譜，悉仍其舊，唯組版新之。

- [`백범일지（국한문-한몬 비교）.pdf`](https://github.com/earm-eas/bbij/releases/download/v1.0.0/baekbeom-gukhanmun-hanmun.pdf)


원저자 김구(1876～1949) 원문은 퍼블릭 도메인. 주해·교감·편집은 도진순, 출판은 돌베개(1997/2016)에 귀속.

原作者 金九(一八七六～一九四九) 原文은 퍼블릭 도메인. 註解·校勘·編輯은 都珍淳, 出版은 돌베개(1997/2016)에 歸屬.

金九（一八七六～一九四九）原文，版權已盡，入於公有。註解、校勘、編輯出於都珍淳，刊行屬돌베개社（1997/2016）。
